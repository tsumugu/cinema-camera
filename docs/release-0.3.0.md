# 0.3.0

Android 15向け、versionCode 3。前版と同じデバッグ署名キー。

- センサー取得専用ワーカーと現像・保存専用ワーカーを分離。RAWをキャッシュファイルへ退避し、JPEGをコピーしてImageProxyを閉じた時点で次の撮影を開始。取得中・現像保存待ち合わせて最大3枚。
- 現像はプレビューとは独立したオフスクリーンEGLで行う。外部ビューアーへ移った後も、取得済み写真の現像・保存を継続。取得途中で中断した写真はキャンセル。
- OrientationEventListenerで画面回転ロックと独立して端末方向を取得。撮影要求ごとにImageCaptureのtargetRotationを設定。JPEGへの再撮影もその撮影の向きを引き継ぐ。RAW/JPEGはそれぞれImageInfoの回転をピクセルへ適用し、MediaStoreの向きは0、縦横寸法も記録。
- 青みを暗部に加えて中間調にも広げ、従来のB1より強化。暗部の階調とG1粒子は維持。
- シャッター左に最新写真のサムネイルを表示し、Pictures/CinemaCameraを外部フォルダ対応アプリで開く。対応アプリがなければ初期位置を保存先に指定したシステム画像選択画面から外部ビューアーで開く。Googleフォトの名前付き端末フォルダ直開きには共通APIがないため保証しない。

ビルド: tools/build-cached-apk.py。Javaコンパイル→D8→AAPT2→ZIP整列→デバッグ署名。手元のSDKと依存キャッシュを使用し通信なし。今回のシェーダーはソースからAPKへ再格納。

ユーザーの指定によりテスト・lint・実機動作検証は実施していない。回転についてはコードの原因調査と修正を行った。端末上の新しい撮影結果は未確認。
