# 0.4.0

Android 15向け、versionCode 4。前版と同じデバッグ署名キー。

上部に「設定」を追加し、メニュー内の「フィルター調整」から全体の強さ・青み・彩度・コントラスト・粒子を調整可能。撮影画面には調整値やスライダーを常時表示しない。

プレビューに即時反映し、「保存」でSharedPreferencesへ保存。キャンセル・戻る・外側タップ・保存前の画面中断では元に戻す。「初期値」は未保存のドラフトとして適用。

初期値は全体100%、青み45%、彩度86%、コントラスト100%、粒子100%。青み100%は0.3.0と同じ。初回の更新後は自動的に青み45%を使う。保存後はユーザーの値を優先する。全体の強さ0%でもRAWからの基本現像は行う。

LookSettingsは不変で、同じuniform設定をプレビューと写真レンダラーへ適用。各PhotoJobに撮影時点の設定を保存し、現像待ちやJPEGフォールバックにも保持する。

ビルドはtools/build-cached-apk.pyで通信なし。ユーザーの指定を引き継ぎ、テスト・lint・実機検証は実施していない。
