# 0.5.0

Android 15向け、versionCode 5。前版と同じデバッグ署名キー。

OrientationEventListenerで取得する端末方向を露出表示にも適用。縦・左右の横向き・逆さの4方向で、フォーカス位置を基準に露出のレール、太陽アイコン、EV数値をまとめて回転する。写真保存の回転設定と同じ向きを使用し、画面の自動回転設定には依存しない。

プレビューの画像領域を逆変換し、回転後も露出表示の位置を画像内に収める。グリッド、水平器、ピントの測定座標はそのまま。

ドラッグ変位も表示の回転に合わせて射影し、撮影者から見た上方向が明るく、下方向が暗くなる。操作中に端末方向が切り替わった場合はそのドラッグを終了し、次のタップを現在のEVから開始する。

RAW優先、現像中の撮影、フィルター調整の保存、外部フォルダ表示は維持。

ビルドはtools/build-cached-apk.pyで通信なし。ユーザーの指定を引き継ぎ、テスト・lint・実機検証は実施していない。
