# 0.8.0 — EXIF・撮影位置・マニュアル操作

Android 15向け、versionCode 9。前版と同じ署名。

## 撮影情報

撮影画像のセンサー時刻とCaptureResultを照合し、実際の露光時間、ISO、絞り、焦点距離、露出補正、露出モード、WB、フラッシュを標準EXIFに記録。撮影日時・タイムゾーンと機種情報も保存。RAWとJPEG両方が同じ結果を参照できるよう、結果を一度の参照で消費せず、上限8件のキャッシュに保持する。結果が取れなければ元JPEGの該当EXIFを利用し、不明な撮影値は捏造しない。センサー時刻がREALTIMEなら実際の露光時刻から日時を計算する。

## 撮影位置

GPS・NETWORK・PASSIVEの利用可能なプロバイダから、カメラ画面が前面の間だけ位置を取得。新しい位置権限は正確／概算を一緒に要求し、拒否時も撮影可能。以後の設定OFFと、再許可への端末設定導線を用意。60秒より古い位置、未測位、権限なしではGPSを記録しない。測位精度が低い場合もその値を水平精度タグに記録する。

撮影要求時の座標、測位時刻、高度・精度・方法を永続ジョブに保管して、再起動後の現像も同じ位置を使う。座標は標準GPSタグだけに書き、UserCommentには複製しない。既存写真のGPSは変更しない。バックグラウンド位置権限やネットワーク権限、新しい外部SDKは追加しない。

## マニュアル

シャッター右と設定メニューから、M露出（シャッター速度・ISO）と独立したMF。端末が宣言するMANUAL_SENSOR、AE OFF、露光時間・感度・最大フレーム時間、AF OFF・フォーカス距離の範囲で有効化。非対応項目は無効。絞り・WBの手動操作は今回含まない。

Camera2InteropのリクエストにAE OFF・露光時間・ISO・フレーム時間、必要ならAF OFFとフォーカス距離を設定。既存の輪郭強調OFF要求も同じリクエストへ統合し、設定を上書きし合わないようにした。AUTOへ戻すと手動キーの上書きを解除。設定適用中は撮影を待機し、成功後に設定を保存。撮影中は設定を切り替えない。MではフラッシュとEV補正を無効化し、MF時のタップAFも抑止する。長秒露光に合わせて取得タイムアウトを延長。

## 確認範囲

依存ライブラリは増えていない。ユーザーの従来の指定により、テスト・lint・実機検証は省略しAPK生成のみ。moto g66j 5Gの実際のマニュアル対応範囲、指定値の反映、GPS取得・EXIFの外部ビューアー表示は未検証。端末の省電力・測位状態・共有アプリのEXIF除去に影響される。
